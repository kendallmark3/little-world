# Glossary

- **Tick** — one simulated minute.
- **Task** — what an inhabitant is doing (`eat`, `harvest`, `chop`, `build`, …). Each has a walk phase and a work phase.
- **Reason** — the plain-language cause the inhabitant chose a task; shown as "Why" in the inspector.
- **Site** — a house under construction. Becomes a `house` when progress reaches 100%.
- **Chronicle** — the activity log. Only real events are written to it.
- **Display position** — where the renderer draws someone; chases the simulation position at a capped speed.
- **New Beginnings** — the first settlement.
